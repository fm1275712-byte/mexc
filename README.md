# MEXC Multi-Portfolio Rebalancer (Discord Bot) - Full Control

بوت ديسكورد لإدارة محافظ متعددة على منصة MEXC Spot مع تحكم كامل.

## المميزات الجديدة

- **تشغيل الاستراتيجية** → يشتري العملات بالمبلغ المخصص للمحفظة فقط (لا يمس باقي الرصيد)
- **إيقاف** → يبيع كل عملات المحفظة ويرجعها USDT **بدون حذف** المحفظة
- لو ضغطت تشغيل وهي شغالة → يسألك هل تريد زيادة الاستثمار
- زيادة استثمار (مع خيار الشراء الفوري للمبلغ الإضافي)
- إعادة توازن (معاينة + تنفيذ) داخل المبلغ المخصص فقط
- إضافة / حذف عملات
- إنهاء المحفظة (يبيع أولاً لو شغالة ثم يحذف)

## المتغيرات في Railway

| المتغير | الوصف |
|---------|--------|
| `DISCORD_BOT_TOKEN` | توكن بوت الديسكورد |
| `MEXC_API_KEY` | مفتاح API من MEXC |
| `MEXC_API_SECRET` | السر |
| `DATABASE_URL` | رابط PostgreSQL |
| `ADMIN_DISCORD_ID` | (مستحسن) رقم الديسكورد الخاص بك |

## أوامر السلاش

- `/start` — القائمة الرئيسية
- `/portfolios` — محافظك
- `/balance` — رصيد الحساب الكامل
- `/create` — إنشاء محفظة جديدة

## أزرار التحكم داخل المحفظة

| الزر | الوظيفة |
|------|---------|
| ▶️ تشغيل الاستراتيجية | يشتري بالمبلغ المخصص |
| ⏹️ إيقاف | يبيع ويرجع الفلوس (المحفظة تبقى) |
| 💰 زيادة استثمار | يزود المبلغ المخصص |
| ⚖️ إعادة توازن | معاينة أو تنفيذ |
| 🪙 العملات | إضافة / حذف |
| 📋 تفاصيل | عرض الحالة الحالية |
| 🗑️ إنهاء المحفظة | حذف نهائي |

## النشر على Railway

1. ارفع الكود على GitHub
2. Deploy from GitHub + أضف PostgreSQL
3. Variables:
   - `DISCORD_BOT_TOKEN`
   - `MEXC_API_KEY`
   - `MEXC_API_SECRET`
   - `DATABASE_URL` = `${{Postgres.DATABASE_URL}}`
   - `ADMIN_DISCORD_ID`
4. Start Command: `python bot.py`

## ملاحظات مهمة

- البوت يحترم المبلغ المخصص لكل محفظة ولا يمس باقي الرصيد.
- يفضل عدم وضع نفس العملة في أكثر من محفظة شغالة في نفس الوقت.
- الـ migration يعمل تلقائي عند التشغيل (يضيف `is_running` ويحول الأعمدة القديمة).
