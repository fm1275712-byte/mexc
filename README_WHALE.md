# MEXC Bot + Whale Alert Auto Execution

## التعديلات المضافة

1. **تحليل تلقائي لرسائل Whale Alert**
   - يفهم صيغة: `X $BTC (Y USD) transferred from A to B`
   - يستخرج المبلغ بالدولار والرمز والاتجاه

2. **قواعد القرار الذكية**
   - **BTC/ETH/... سحب من منصة → unknown** = BUY (تجميع)
   - **BTC/ETH/... إيداع في منصة** = SELL (استعداد بيع)
   - **USDC/USDT إيداع في منصة** = BUY (فلوس جاهزة للشراء)
   - **USDC/USDT سحب من منصة** = SELL

3. **مطابقة المصدر**
   - لو الرسالة من Whale Alert والمصدر اسمه فيه `Whale` هيتم استخدامه أوتوماتيك

## طريقة الاستخدام

1. ارفع الملفات الجديدة (خصوصاً `bot.py`) على السيرفر
2. أعد تشغيل البوت
3. من داخل البوت أضف مصدر إشارة بالاسم: **WhaleAlert**
4. اربط محافظ الشراء/البيع + حد أدنى للقيمة
5. استخدم TeleFeed (أو أي Forwarder) لنقل رسائل `@whale_alert_io` إلى مجموعتك

## اختبار سريع

ابعت في المجموعة:

```
🚨 🚨 🚨  1,200 $BTC (90,000,000 USD) transferred from #Coinbase to unknown wallet
Details
```

المفروض البوت يرد وينفذ BUY لو الشروط متحققة.
